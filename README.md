# Proyecto de Sistemas — Control de Avance y Documentación (PetCop)

Este es el repositorio de **PetCop**
El espacio está destinado al control de versiones, seguimiento del desarrollo web y almacenamiento de la documentación técnica recopilada y elaborada a lo largo de los últimos meses.


##  Descripción del Proyecto

**PetCop** es un sistema web enfocado en la gestión, registro y validación de datos. Este repositorio centraliza tanto los entregables académicos como el código fuente correspondiente a las distintas fases de desarrollo del sistema.

### Objetivos del Repositorio
* **Control de versiones:** Seguimiento y subida de iteraciones de la interfaz web.
* **Documentación centralizada:** Resguardo de informes, especificaciones y documentos finales del sistema.
* **Validaciones e Interfaz:** Implementación y pruebas de módulos de registro y edición.
